# Veri kaynakları ve lisanslar

`python -m ai_brain build` aşağıdaki açık veri kümelerini **kullanıcının kendi makinesine** indirir.
Bu depo verilerin kendisini içermez; yalnızca indirme ve işleme kodunu içerir.

| Kaynak | Lisans | Atıf |
|---|---|---|
| Vikipedi (Türkçe ve Basit İngilizce), `wikimedia/wikipedia` veri kümesi, 2023-11-01 | CC BY-SA 4.0 / GFDL | Wikipedia katkıcıları, Wikimedia Vakfı |
| ConceptNet 5.7 | CC BY-SA 4.0 | Speer, Chin & Havasi (2017), ConceptNet 5.5, AAAI. conceptnet.io |
| Kur'an-ı Kerim mealleri: Diyanet İşleri (tr.diyanet), Sahih International (en.sahih) | Tanzil kullanım koşulları (değiştirmeden, kaynak gösterilerek) | Tanzil Project — tanzil.net |
| Project Gutenberg kitapları (Aristoteles, Platon, Kant, Kitab-ı Mukaddes KJV...) | ABD'de kamu malı; Project Gutenberg Lisansı | gutenberg.org |
| Vikipedi API (canlı öğrenme, `learn`) | CC BY-SA 4.0 | Wikipedia katkıcıları |

Bu verilerden üretilen bilgi tabanını (`data/memory.db`) paylaşacaksanız CC BY-SA 4.0'ın
"aynı lisansla paylaş" ve atıf koşullarına uyunuz.
